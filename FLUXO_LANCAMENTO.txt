╔══════════════════════════════════════════════════════════════════════════════╗
║                    FLUXO DE LANÇAMENTO DE JOGO                              ║
║                     com HUD Responsivo (Mobile/Desktop)                      ║
╚══════════════════════════════════════════════════════════════════════════════╝

1️⃣ USUÁRIO CLICA EM "JOGAR"
   └─ Frontend: LaunchButton.handleLaunchGame()
      │
      ├─ Extrai gameId de: game.slug || game.gameId || game.name
      ├─ Normaliza: "Fortnite" → "fortnite"
      └─ Envia POST para backend: /api/games/launch


2️⃣ BACKEND RECEBE REQUISIÇÃO
   └─ gamesController.launchGame()
      │
      ├─ Carrega jogos de: games/executables/
      │  └─ Cada pasta/shortcut = 1 jogo
      │
      ├─ Busca Case-Insensitive
      │  └─ "fortnite" == "Fortnite" ✅
      │
      ├─ Busca Fuzzy (aproximada)
      │  └─ "fort" match com "fortnite" ✅
      │
      ├─ Se não encontrar
      │  └─ Retorna: {success: false, available: ["minecraft", ...]}
      │
      └─ Se encontrar
         ├─ Valida permissões/arquivo
         ├─ spawn(app.path) → Executa em novo processo
         └─ Retorna: {success: true, message: "Fortnite launched"}


3️⃣ FRONTEND RECEBE RESPOSTA
   └─ LaunchButton.js
      │
      ├─ Se success === true
      │  ├─ Mostra: "✅ Fortnite launched successfully"
      │  ├─ Timeout: 5 segundos
      │  └─ Estado: setIsLaunching(false)
      │
      └─ Se success === false
         ├─ Mostra: "❌ Game not found: fortnite"
         ├─ Exibe sugestões
         └─ Estado: setIsLaunching(false)


4️⃣ RENDERIZAÇÃO DO HUD (Se gameRunning)
   
   DESKTOP (Controle Xbox)
   └─ GamepadHUD.js
      ├─ D-PAD (esquerda inferior)
      ├─ Botões ABXY (direita inferior)  
      ├─ Triggers LT/RT (topo)
      ├─ Sticks analógicos
      └─ Press BACK+START para ocultar


   MOBILE/TOUCH (Celular ou tela <768px)
   └─ GamepadHUDMobile.js
      ├─ Detecta automaticamente via userAgent
      ├─ D-PAD (toque inferior esquerdo)
      ├─ Botões ABXY (toque inferior direito)
      ├─ Triggers (toque topo)
      └─ Duplo-clique centro para ocultar
